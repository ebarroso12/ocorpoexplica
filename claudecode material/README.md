## Estrutura planejada

```
claudecode material/
├── 00-indice/          índices numerados (A01…) e seleção das aulas prioritárias
├── apostilas/          apostilas em ordem, com numeração e páginas
├── transcricoes/       texto de cada aula (fonte das apostilas)
└── videos-editados/    cortes/aceleração/legendas das aulas prioritárias (se viável)
```

## Observação sobre direitos

O conteúdo das aulas é material pago da O Corpo Explica®. Estas apostilas são para estudo
pessoal; mantenha este repositório **privado**.
